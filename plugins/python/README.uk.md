# python

[English](README.md) · **Українська**

Конвенції для коду на Python: інструменти, структура, типізація й перевірки в одному скілі, тести в іншому. Кожна з них —
скіл із `paths:`, тож Claude Code завантажує його, коли сесія торкається відповідного файлу.
Нічого специфічного для проєкту тут немає: таблиця обов'язкових перевірок і власні обмеження
проєкту лишаються в проєкті. Потребує `core`.

## Встановлення

Коли маркетплейс `agent-kit` уже додано (див. [кореневий README](../../README.uk.md)):

```bash
claude plugin install python@agent-kit
```

## Скіли

| ID | Скіл | Завантажується для | Що охоплює |
| --- | --- | --- | --- |
| 1 | `python:code` | `**/*.py`, `**/pyproject.toml` | Закріплена версія, uv замість pip, залежності як рішення, скрипти PEP 723, ruff; структура скриптів і пакетів, час імпорту, імпорти й цикли; типізація (`X \| None`, слабкі типи входу, заморожені dataclass, Protocol, можливості за версією); де ловити помилки; які перевірки запускати, перш ніж вважати зміну готовою |
| 2 | `python:tests` | `**/test_*.py`, `**/*_test.py`, `**/conftest.py`, `**/tests/**/*.py` | Раннер проєкту, тести через контракт, точні перевірки, межі, ізоляція, дублери, спершу регресійний тест, чого не тестувати |

Опис скіла показується в кожній сесії, а тіло завантажується лише тоді, коли модель його викликає
(див. [спайки](../../docs/spikes.uk.md), S2 і побічна знахідка 2). Скіли заповнюють те, що проєкт
лишив відкритим: власні правила проєкту, `pyproject.toml` і навколишній код мають перевагу, коли
вони розходяться.

## Що лишається в проєкті

1. Таблиця обов'язкових перевірок: яка команда для якої теки.
2. Цільові версії вендореного чи upstream-коду, що відрізняються від версії самого проєкту.
3. Правила для тек із приватними даними, шляхи до зразкових даних і запуски на реальних даних.

## kit.json

| ID | Ключ | Хто використовує |
| --- | --- | --- |
| 1 | `commands.check` | `python:code`: перевірки, які треба запустити, перш ніж вважати зміну готовою |
| 2 | `commands.test` | `python:code`, `python:tests`: команда, що запускає тести |

## Як прибрати копії з проєкту

Проєкт, що тримав `.claude/rules/python.md`, може прибрати його загальну частину: `kit doctor` і
`/core:kit-adopt` показують його з [kit-owned.json](kit-owned.json). Власну таблицю перевірок
проєкту залиште в правилі з іншою назвою.
